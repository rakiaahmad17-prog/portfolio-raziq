03 — Write

Write, then publish.

Articles on this site are Markdown files. This page is the editor: write on the left, see it rendered on the right, publish straight to the live site. Nothing is stored here — drafts stay in this browser until you send them.

Connect your GitHub token

Publishing needs one thing: a token that is allowed to write to this repository. It is kept in this browser only and is sent to api.github.com and nowhere else.

  1. Open github.com/settings/personal-access-tokens.
  2. Choose Fine-grained token, repository access Only select repositories → portfolio-raziq.
  3. Give it Contents: Read and write. Nothing else.
  4. Generate, copy, and paste it below.
